# Frontend Assets

Assets used by the Streamlit frontend:

- `favicon.png`: browser-tab icon (drone mark).
- `samples/`: five held-out test recordings for the "Try a sample" buttons (Svanström dataset, CC0; ESC-50, CC BY-NC 3.0).

The HOME hero image is `background.jpg` in the project root. If it is missing, the app uses a gradient fallback.
